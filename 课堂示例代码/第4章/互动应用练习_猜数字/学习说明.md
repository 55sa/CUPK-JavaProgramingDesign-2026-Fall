## 2. 类与对象教学 / Классы и объекты / Understanding classes and objects / Klaslar we obýektler

**中文**

- `GuessGame` 是描述一局游戏的类，负责保存状态和判断猜测。字段包括答案 `secret`、次数上限 `maxAttempts`、已用次数 `attempts`、胜利状态 `won`。
- 构造方法与类同名，没有返回类型，在创建对象时初始化字段。`this.secret` 表示当前对象的字段；右侧同名的 `secret` 是构造参数。
- `new GuessGame(secret, 5)` 创建一个对象，变量 `game` 保存该对象的引用。每个游戏对象都有独立的实例字段。
- `game.guess(number)` 调用对象的方法，把用户输入作为实参传入。方法更新次数，并返回 -1（偏小）、1（偏大）或 0（猜中）。
- `GuessNumberPractice` 是包含 main 的主类，负责创建对象、读取输入和显示提示。`private` 字段由游戏类内部管理，主类通过方法与游戏对象交互。

**Русский**

- `GuessGame` — класс, описывающий одну игру. Он хранит состояние и проверяет догадки. Поля: ответ `secret`, лимит `maxAttempts`, использованные попытки `attempts` и состояние победы `won`.
- Конструктор имеет то же имя, что и класс, и не указывает тип возвращаемого значения. Он инициализирует поля при создании объекта. `this.secret` — поле текущего объекта, а `secret` справа — параметр конструктора.
- `new GuessGame(secret, 5)` создаёт объект; переменная `game` хранит ссылку на него. У каждого игрового объекта собственные значения полей экземпляра.
- `game.guess(number)` вызывает метод объекта, передавая введённое число как аргумент. Метод обновляет счётчик и возвращает -1 (число слишком мало), 1 (слишком велико) или 0 (угадано).
- `GuessNumberPractice` — главный класс с методом main. Он создаёт объект, читает ввод и выводит сообщения. Поля `private` управляются внутри игрового класса; главный класс взаимодействует с объектом через методы.

**English**

- `GuessGame` describes one game. It stores state and evaluates guesses. Its fields are the answer `secret`, limit `maxAttempts`, attempts used `attempts`, and win state `won`.
- A constructor has the class name and no return type. It initializes fields during object creation. `this.secret` refers to the current object's field; `secret` on the right is the constructor parameter.
- `new GuessGame(secret, 5)` creates an object; `game` stores a reference to it. Each game object has independent instance fields.
- `game.guess(number)` calls the object's method with the user's input as an argument. The method updates the count and returns -1 (too low), 1 (too high), or 0 (correct).
- `GuessNumberPractice` contains main. It creates the object, reads input, and displays messages. Private fields are managed inside the game class; main interacts with the object through methods.

**Türkmençe**

- `GuessGame` bir oýny beýan edýän klasdyr. Ol oýnuň ýagdaýyny saklaýar we girizilen sanlary barlaýar. Meýdanlary: jogap `secret`, synanyşyklaryň çägi `maxAttempts`, ulanylan synanyşyklar `attempts` we ýeňiş ýagdaýy `won`.
- Konstruktoryň ady klasyň ady bilen birmeňzeşdir, onuň yzyna gaýtarýan görnüşi ýazylmaýar. Obýekt döredilende konstruktor meýdanlaryň başlangyç bahalaryny belleýär. `this.secret` häzirki obýektiň meýdanydyr, sag tarapdaky `secret` bolsa konstruktoryň parametridir.
- `new GuessGame(secret, 5)` täze obýekt döredýär; `game` üýtgeýjisi şol obýekte salgylanmany saklaýar. Her oýun obýektiniň öz aýratyn meýdan bahalary bolýar.

- `GuessNumberPractice` main metody ýerleşýän esasy klasdyr. Ol obýekt döredýär, girizilen maglumatlary okaýar we habarlary görkezýär. `private` meýdanlar oýun klasynyň içinde dolandyrylýar; esasy klas oýun obýekti bilen metodlaryň üsti arkaly işleýär.
