第1章 Java 入门——学生编程练习
Chapter 1: Getting Started with Java — Student Programming Exercises

使用方法：
1. 每个 .java 文件单独打开。
2. 搜索 TODO，填写或修改对应代码。
3. 文件名不要修改，public 类名必须与文件名一致。
4. 先预测结果，再编译运行。

练习列表：
1. HelloPractice.java：使用 println 输出三行个人信息。
2. CourseCardPractice.java：完成一张课程信息卡。
3. TwoClassPractice.java：在一个文件中定义两个类并调用方法。
4. MethodCallPractice.java：完成静态方法并从 main 调用。
5. SumDebugPractice.java：补全循环，计算 1 到 100 的和。
6. CommandLinePractice.java：读取命令行参数并输出欢迎语。

建议：学生完成后与章节目录中的参考程序比较，但不要直接复制。

参考答案位于：参考答案/ 文件夹。
