第2章 基本数据类型与数组——学生编程练习
Chapter 2: Basic Data Types and Arrays — Student Programming Exercises

使用方法：
1. 每个 .java 文件单独打开。
2. 搜索 TODO，填写变量、表达式、循环或方法体。
3. 使用 IntelliJ IDEA 运行；含 Scanner 的题目需要在控制台输入数据。
4. 先用纸笔预测输出，再运行验证。

练习列表：
1. BasicTypesPractice.java：声明并输出 int、long、char。
2. IntDivisionPractice.java：比较整数除法和浮点除法。
3. LongLiteralPractice.java：使用 long 计算时间单位。
4. CharUnicodePractice.java：字符与 Unicode 编码转换。
5. ConversionPractice.java：自动转换和强制类型转换。
6. ScannerRectanglePractice.java：输入长宽并计算矩形。
7. ArrayStatisticsPractice.java：计算数组总和、平均值、最大值和最小值。
8. BinarySearchPractice.java：补全折半查找方法。

提高要求：每完成一题，至少修改一组测试数据并再次运行。

参考答案位于：参考答案/ 文件夹。
