Java 程序设计手写作业（共 4 份）
Java Programming Handwritten Homework (4 Assignments)

作业 1：基本数据类型、运算符和分支语句（第 1—3 章）
作业 2：类与对象（第 4 章）
作业 3：继承、重写和多态（第 5 章）
作业 4：接口与实现（第 6 章）

要求：
1. 写在作业本上，保持缩进整齐。
2. 先写题号，再写答案或完整 Java 代码。
3. 不要求运行程序，但代码应包含必要的类、方法和分号。
4. 每份作业控制在一页左右。

Requirements:
1. Complete the work by hand with clear indentation.
2. Write the task number before each answer or Java program.
3. Running the code is not required, but the Java syntax should be complete.
4. Keep each assignment to about one page.
